## Question

Which minimum macOS, hardware architectures, browsers, auction platforms, regions, and window states are explicit launch commitments, so capture feasibility can be validated against a finite matrix before architecture is locked?

The [macOS research](02-macos-capture-and-release.md) makes macOS 14 a candidate floor for original still capture and the system picker; it does not select that floor or prove platform compatibility. Decide Apple Silicon versus Intel, the first browser(s), whether Whatnot, TikTok Live and eBay Live are examples or all required at launch, and whether normal visible windows suffice initially versus player/fullscreen Spaces, minimized windows or Picture-in-Picture.

Choose a small matrix suitable for disposable experiments, retaining both raw-card details and slab-label readability. Include the actual region and manual buyer flow rather than merely confirming that a homepage opens. Source pixels, crop/upload scope, and manual auction usability are separate concerns. Return any platform limitation as an explicit scope decision.
