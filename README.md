# not-tcg

An open-source macOS auction companion for English Pokémon cards: hotkey capture of an auction video, bring-your-own AI identification, and free price-evidence lookup for manual bidding.

## Planning

The canonical decision map is GitHub issue #1: [Find the route to a build-ready macOS auction companion](https://github.com/LowMillzz/not-tcg/issues/1). Tickets are native sub-issues of the map; open, unassigned, unblocked sub-issues form the frontier. Resolved decisions live only on their ticket.

Research reports are in [`docs/research`](docs/research), and the shared vocabulary is in [`GLOSSARY.md`](GLOSSARY.md). The scan-identity prototype is preserved on the `prototype/scan-identity-states` branch and is not merged.

This map ends at a build-ready specification. A separate implementation map follows once specification readiness closes; production code is not part of this effort.

## Status

Discovery. No production app, release license, or price-data source has been selected yet. Nothing in this repository authorizes capturing a live auction, changing a Mac host, or making paid provider calls.
